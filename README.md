# Stabi Survive

Community-made browser game prototype inspired by the Stabilizer ecosystem.

## v0.1

- Top-down free movement
- Mobile virtual joystick
- Stabilize pulse attack
- Dash
- HP, USDZ, survival timer and waves
- Slippage, MEV, Price Impact and MEV Bot enemy types
- Increasing difficulty
- Game-over and replay loop

## Run locally

Open `index.html` in a browser.

## Project rule

This repository is standalone and should not modify or depend on the Stabi Runner repository during development.
